# MAVROSPY
ROS2 Humble node to interact with [MAVROS](https://wiki.ros.org/mavros) for basic UAV control.

This current repo is supported on a PX4 (v1.15.4) flight controller with a RPi4 (Ubuntu 22.04 MATE), Jetson Nano (JetPack 4.6), or Jetson Orin Nano (Jetpack 6.2) companion computer.

Documentation for motion capture utilizes the [Qualisys Track Manager]("https://www.qualisys.com/software/qualisys-track-manager/").
